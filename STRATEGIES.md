## 2. Bollinger Grid LONG (основная, 3x)

**Суть:** покупка на отскоке от нижней полосы Bollinger. Статистически цена возвращается к средней 70%+ случаев.

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 3x |
| **Маржа** | $15 (Score ≥7), $10 (≥5.5), $5 (<5.5) |
| **Вход** | Лимитный ордер Buy на −3% ниже Lower BB Daily |
| **TP** | 20% позиции на Middle BB, 80% на Upper BB |
| **SL** | −7% от Lower BB |
| **Макс позиций** | 12 (risk.max_long_positions) |
| **Cooldown после SL** | 4 часа |
| **Ограничения** | M5/M3 BB width > 100% → вход блокируется |
| **Приоритет** | margin → max_positions → sector_limit → correlation_stop → scoring |

### Scoring (0-10)

```
Score = Σ w_i × metric_i / max_score × 10

Метрики:
  Tier-бонус ×2.0     S=10, A=7, B=4, C/D=1
  BB% положение ×1.5  0% = нижняя полоса, идеал <30%
  Объём 24ч ×1.0      log-нормализация
  Дней падения ×1.0    до 7 дней подряд
  Недельный BB% ×1.0   Weekly BB контекст
  Месячный BB% ×1.0    Monthly BB контекст
  Фандинг ×0.5         отрицательный = бонус
  RSI(14) ×1.0         <30 = 10, >70 = 0
  BB Squeeze ×1.0      узкие полосы перед расширением

Мин порог: 5.5/10
```

### Tier-классификация

```
Tier S:  BTC, ETH
Tier A:  SOL, LTC, XRP*, ADA, DOT, LINK, UNI, AVAX*, SUI*, NEAR, APT*
Tier B:  ARB, OP, AAVE, INJ, ONDO, ENA, FET, WLD, ATOM, ALGO, RUNE
Tier C/D: всё остальное

* = ONE_WAY (SHORT невозможен)
```

## 3. Bollinger Grid SHORT (хедж, 3x)

**Суть:** шорт при перегреве — когда цена у верхней полосы BB (>85%), статистически возвращается к середине.

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 3x |
| **Маржа** | $10 |
| **Вход** | Лимитный Sell на +2% выше рынка (ждём отскока для лучшей цены) |
| **TP** | Middle BB (через takeProfit в trading-stop, единый вызов с SL) |
| **SL** | +5% (Tier A/B), +7% (Tier C/D) |
| **Порог BB** | >85% Daily |
| **Макс позиций** | 3 |
| **Макс удержание** | 72 часа — авто-закрытие |
| **Доля шортов** | Не более 20% от всех позиций |
| **Кулдаун** | 2 часа на монету |
| **Исключены** | XRP, ONDO, WLFI, ENJ, ESPORTS, AVAX, APT, SUI |

## 4. Шлак-шорт (Junk Mode, 3x)

**Суть:** для Tier C/D монет фиксированный SL не работает — слишком волатильны. Вместо SL — жёсткий лимит убытка $30 и DCA-лесенка.

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 3x |
| **Маржа** | $10 |
| **Триггер** | Дневной рост ≥80% **И** BB Daily >70% |
| **Вход** | Лимитный Sell на +2% выше рынка |
| **SL** | **Нет** |
| **Max убыток** | −$30 на позицию (hard market-close) |
| **DCA-уровни** | +100% и +120% от входа (лимитные Sell того же размера) |
| **Макс позиций** | 2 |

### Конфиг (выключен по умолчанию!)

```yaml
strategy:
  short:
    junk:
      enabled: false
      min_pump_pct: 80
      dca_levels: [1.0, 1.2]
      max_loss_per_position: 30
      max_positions: 2
```

## 5. SL Re-entry (лесенка)

**Суть:** после выбивания по SL на монете с хорошим скором — перезаход с уменьшенной маржей.

| Параметр | Значение |
|----------|---------|
| **Триггер** | SL + score ≥6 |
| **Задержка** | 4 часа |
| **Вход** | Текущий Lower BB Daily (пересчитывается) |
| **Маржа** | ×0.5 от предыдущей |
| **Максимум** | 2 re-entry за 24 часа на монету |
| **SL** | Пересчитывается от нового входа |

---

## 6. DCA (лесенка усреднения)

**Суть:** докупка при падении для улучшения средней цены входа.

| Уровень | От входа | Множитель маржи |
|---------|----------|-----------------|
| 1 | −5% | $10 |
| 2 | −10% | $20 |
| 3 | −15% | $40 |

- **max_margin_per_symbol:** $80
- **max_dca_count:** 2 добавки
- SL/TP пересчитываются от средней цены после DCA

## 7. ⚡ BB Scalping M5 (x10)

**Суть:** на M5 свечах цена возвращается к Middle BB в 70%+ случаев. x10 превращает 1% хода в 10% прибыли.

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 10x |
| **Маржа** | $10 |
| **Таймфрейм** | M5 |
| **LONG** | Цена у Lower BB M5 + RSI(14) < 35 |
| **SHORT** | Цена у Upper BB M5 + RSI(14) > 65 |
| **SL** | 3% от входа |
| **TP** | Middle BB M5 |
| **Макс позиций** | 3 |
| **Кулдаун** | 1 час на монету |
| **Тиры** | Только A/B |

### Логика
```
Цена касается полосы → отскок → TP на Middle.
При x10: 1% движения = 10% на маржу ($10 → +$1 за ход).
RSI-фильтр отсеивает ложные пробои.
```

## 8. ⚡ Mean Reversion Extreme (x10)

**Суть:** при экстремальных BB% (<5% или >95%) на дневном таймфрейме — высокая вероятность возврата к среднему (10-20% движения).

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 10x |
| **Маржа** | $10 |
| **Таймфрейм** | Daily |
| **LONG** | BB% < 5% |
| **SHORT** | BB% > 95% (кроме ONE_WAY) |
| **SL** | 5% от входа |
| **TP** | Middle BB Daily |
| **Макс позиций** | 5 |
| **Кулдаун** | 2 часа на монету |
| **Тиры** | Только A/B |

### Отличие от основной стратегии
- Выше плечо (10x vs 3x)
- Жёстче условия входа (экстремальные BB%, а не просто касание)
- Быстрее выход (TP на Middle, не на Upper)

## 9. ⚡ Funding Rate Momentum (x10)

**Суть:** экстремальный фондинг притягивает арбитражёров. Когда ставка >0.1% — лонгисты платят шортистам каждые 8 часов.

### Параметры

| Параметр | Значение |
|----------|---------|
| **Плечо** | 10x |
| **Маржа** | $10 |
| **Таймфрейм** | Daily |
| **LONG** | Фондинг < −0.1% (шортисты платят) + BB% < 15% |
| **SHORT** | Фондинг > +0.1% (лонгисты платят) + BB% > 85% |
| **SL** | 4% от входа |
| **TP** | Middle BB Daily |
| **Макс позиций** | 3 |
| **Кулдаун** | 4 часа на монету |
| **ONE_WAY** | SHORT исключён |

### Допдоход от фондинга
```
Фондинг 0.1% × 3 раза/день × 10x плечо ≈ 3% к марже в день
При $10 марже: +$0.30/день только за удержание позиции
```

## 10. ATR Risk Sizing (защитный слой)

**Не самостоятельная стратегия** — слой валидации для ВСЕХ x10-входов.

### Формула

```
ATR = Average True Range(14) на 15-минутных свечах
SL_distance = 1.5 × ATR
SL_distance_pct = SL_distance / price
Risk_USDT = Balance × 1%
Max_Margin = Risk_USDT / (SL_distance_pct × Leverage)
Qty = Max_Margin × Leverage / Price
```

### Две функции

1. **`validate_entry()`** — перед x10-входом проверяет что маржа не превышает безопасный лимит. Если риск > 1.5× допустимого → вход блокируется.

2. **`check_position_risk()`** — каждые 10 минут проверяет все позиции. Если риск позиции > 2% от баланса → алерт.

### Пример расчёта
```
Баланс: $500
Цена SOL: $100
ATR(14): $2.50
SL_distance = 1.5 × $2.50 = $3.75 (3.75%)
Risk_USDT = $500 × 1% = $5
Max_Margin = $5 / (0.0375 × 10) = $13.33
→ $10 маржа входит в лимит ✅
```

## 11. Интеграция в главный цикл

```
Каждые 30 сек (лёгкий цикл):
  ├── fetch_positions / fetch_orders
  ├── detect_changes (SL/TP/CLOSED/NEW)
  ├── check_and_fix_sl (каждые 4 цикла)
  ├── auto_tp / trailing_sl
  ├── instant_tp (NEAR etc.)
  └── лимит шортов + margin alerts

Каждые 5 мин (HEAVY_CYCLE):
  ├── check_overbought → SHORT-кандидаты
  ├── check_auto_short → SHORT-входы
  ├── check_sl_reentry → перезаходы после SL
  ├── check_junk_dca → DCA для шлак-шортов
  ├── check_correlation → матрица + dedup (24ч)
  ├── check_pumps → детектор пампов
  ├── check_squeeze → BB-сжатие
  ├── check_rsi_divergence → RSI-дивергенции
  ├── check_funding_flip / check_funding_pump
  ├── check_regime → рыночный режим
  ├── check_daily_drawdown → просадка
  └── dashboard + funding_tracker + margin_alerts

Каждые 10 мин (HEAVY_CYCLE × 2 = X10-стратегии):
  ├── fetch_balance
  ├── check_scalp_signals → validate_entry → execute_scalp
  ├── check_mean_revert  → validate_entry → execute_mean_revert
  ├── check_funding_signals → validate_entry → execute_funding_entry
  └── check_position_risk (все позиции)
```

## 12. Риск-менеджмент (общий)

### Параметры

| Параметр | Значение |
|----------|---------|
| max_drawdown_pct | 15% от пика |
| max_total_margin | $500 |
| max_daily_loss | $50 |
| max_long_positions | 12 |
| max_per_sector | 3 |
| drawdown_mode | peak (от пикового баланса) |
| emergency_close_all | true |

### Защиты

- **Каскадная ликвидация:** если mark ближе к liqPrice чем к SL × 0.5 → market-close
- **Лимит шортов:** ≤20% от всех позиций (алерт раз в 24ч)
- **Correlation stop:** LONG >80% → LONG-входы блокируются
- **Graceful shutdown:** SIGTERM → проверить SL на всех позициях → сохранить снепшоты → exit 0

### Секторы

| Сектор | Монеты |
|--------|--------|
| Major | BTC, ETH |
| L1 | SOL, SUI, APT, NEAR, AVAX, ADA, DOT |
| DeFi | AAVE, UNI, INJ, RUNE |
| AI | FET, WLD |
| Meme | DOGE |

## 13. Состояние рынка (Regime Detection)

По BTC и ETH определяется текущий режим:

| Режим | BB% | Волатильность | Поведение |
|-------|-----|---------------|-----------|
| TRENDING_UP | >70% | — | LONG предпочтительнее |
| TRENDING_DOWN | <30% | — | SHORT предпочтительнее |
| CHOPPY | 40-60% | LOW | Осторожно, ждать сигналов |
| HIGH_VOL | — | HIGH | Уменьшить размер позиций |
| LOW_VOL | — | LOW | Нормальный режим |

## 17. Известные ограничения

- Только Bybit USDT фьючерсы (linear perpetual)
- Один аккаунт на инстанс (мульти-аккаунт в v4.0)
- Нет бэктестинга (v4.0)
- Нет веб-дашборда (частично: MCP для AI-агентов)
- ATR-валидация для x10 стратегий — рекомендательная (не блокирует вход если ATR недоступен)

## 18. Быстрый старт

```bash
# Статус
curl http://localhost:8766/health

# Позиции
curl http://localhost:8766/positions

# Скан LONG
curl -X POST http://localhost:8766/scan -H 'Content-Type: application/json' -d '{"mode":"long","limit":5}'

# Войти в SHORT
```
