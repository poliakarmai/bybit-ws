## Этап 1 — (исходная постановка, для истории)

**Проблема:** три потока не сходятся. `trade_history.pnl` Σ −$385.60 (по старому снимку),
`funding_log` Σ −$8.56, `transaction-log.cashFlow` TRADE +$207.91. Расхождение ≈$599 — это
комиссии открытия, которых не видно ни в первом, ни во втором. Пока учёт не сходится,
**все метрики self-learn (composite score, Pareto MC) считаются по кривому PnL**.

**Сделать:** `reconcile.py` в корне репо (read-only, `state.db` на запись не трогать).

1. Тянуть Bybit `GET /v5/account/transaction-log` окнами **по 6 дней** (лимит биржи 7),
   пагинация по `transactionTime` вниз, как в `funding_backfill.py::_iter_window` — переиспользовать
   этот приём, не изобретать (там же `bybit()` из `bybit_ws.api`).
2. Считать из биржи:
   - Σ `fee` по TRADE-записям = **все комиссии, отдельно открывающие и закрывающие**
     (каждая запись = исполнение, значит сплит open/close выводится, гадать не надо);
   - Σ `change` по TRADE, Σ `change` по SETTLEMENT (фандинг), Σ `cashFlow` по TRADE;
   - долю maker/taker по `feeRate` (это же и замер для этапа 4).
3. Сравнить с локальными: `trade_history.pnl`, `trade_history.fees`, `funding_log.cash_flow`.
4. Разбивка по `symbol` и по `strategy`, **`manual=0` и `manual=1` отдельными колонками**.
5. Вывод: таблица «биржа vs БД vs diff» + JSON-отчёт в `~/.local/share/bybit-ws/reconcile-<date>.json`.
   Диффы не прятать: расхождение больше $1 — печатать построчно, где именно.
6. `--days N` (default 30), `--json`, без сети — читать ранее сохранённый отчёт.

**Тест:** `tests/test_reconcile.py` на фикстуре (список записей transaction-log → ожидаемые
суммы), без сети. Плюс `assert` в `__main__`-самотесте, что сплит open/close = Σ fee.

**Готово, когда:** `python3 reconcile.py --days 30` печатает отчёт, `python3 -m pytest tests/test_reconcile.py`
