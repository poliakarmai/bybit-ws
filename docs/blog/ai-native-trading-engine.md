# Я построил AI-native торговый движок на Python. Вот как он устроен

> 8 стратегий, Bollinger Grid, AI-скоринг и полная оркестрация через Hermes-агента. Open source, MIT.

---

## Почему я это сделал

Торговые боты — это либо чёрные ящики за подписку $50/мес, либо самопальные скрипты, которые ломаются в 3 часа ночи. Я хотел систему, которая:

- **Работает без присмотра** — запустил и забыл
- **Понимает контекст** — не просто «RSI < 30 = покупай», а scoring по 9 метрикам
- **Управляется голосом/текстом** — «бери AVAX x10» и AI-агент сам всё исполнит
- **Open source** — чтобы любой мог форкнуть и допилить под себя

Так родился **bybit-ws** — AI-native торговый движок для Bybit.

## Архитектура в двух словах

```
┌─────────────────────────────────────────────────┐
│                  Hermes Agent                     │
│  (AI-оркестратор: голос, текст, авто-вход)       │
└──────────────┬──────────────────────────────────┘
               │ MCP / REST
┌──────────────▼──────────────────────────────────┐
│              bybit-ws (systemd)                   │
│  main.py → 30s цикл                              │
│  ├── auto_entry.py   (LONG по scoring)            │
│  ├── auto_short.py   (SHORT Tier A/B + junk)      │
│  ├── auto_sl.py      (BB-based SL)                │
│  ├── auto_tp.py      (авто-фиксация)              │
│  ├── bb_scalp.py     (⚡ x10 скальпинг M5)        │
│  ├── mean_revert.py  (⚡ x10 разворот экстремумов) │
│  ├── funding_entry.py(⚡ x10 фандинг-моментум)    │
│  ├── dca.py          (лесенка)                    │
│  ├── rpc.py          (HTTP-RPC порт 8766)        │
│  └── dashboard.py    (SVG-дашборд)                │
└──────────────┬──────────────────────────────────┘
               │ WebSocket
┌──────────────▼──────────────────────────────────┐
│               Bybit API v5                        │
└─────────────────────────────────────────────────┘
```

Ключевой принцип: **каждый модуль — отдельный файл**. Не монолит на 5000 строк, а 30+ файлов с чёткими зонами ответственности.

## 8 стратегий — от консерва до экстрима

| Стратегия | Плечо | Таймфрейм | Сигнал |
|-----------|-------|-----------|--------|
| Bollinger Grid LONG | 3x | Daily | Lower BB −3% |
| Bollinger Grid SHORT | 3x | Daily | BB >85% |
| Шлак-шорт (Junk) | 3x | Daily | Рост ≥80% |
| SL Re-entry | 3x | Daily | Lower BB после стопа |
| DCA (лесенка) | 3x | — | −5/−10/−15% от входа |
| ⚡ BB Scalping | 10x | M5 | Касание полосы + RSI |
| ⚡ Mean Reversion | 10x | Daily | BB% <5% или >95% |
| ⚡ Funding Momentum | 10x | Daily | Экстремальный фандинг |
| ⚡ ATR Risk Sizing | слой | 15m | Валидация: SL = 1.5×ATR |

**Главное правило:** система не тыкает пальцем в небо. Каждый вход проходит через **scoring по 8+ метрикам**:

- Tier-бонус (S/A/B/C/D токен)
- BB% положение (0-100%)
- Объём 24ч
- RSI(14)
- Фандинг
- BB Squeeze (сжатие полос)
- Дней падения подряд
- Недельный/месячный BB%

Минимальный порог: **5.5/10**. Всё что ниже — система молча пропускает.

## AI-интеграция: не просто кнопки

Самое интересное — это слой AI. Я использую **Hermes Agent** (от Nous Research) как оркестратор:

- **MCP-сервер**: агент видит позиции, ордера и метрики через стандартизированный протокол
- **REST API**: порт 8766, CORS, rate-limiting, RPC-токен
- **Auto-entry**: агент сам принимает решение о входе на основе scoring
- **GridSignal Bot** (@GridSignalBot в Telegram): real-time сканер, кнопки LONG/SHORT/x10

Пример взаимодействия:

```
Я: «бери AVAX x10 с текущих»
Агент: проверяет BB%, RSI, фандинг, корреляции
       → scoring 7.2/10 → ОК
       → 계산: margin=$5, qty=15.1, SL=−5%
       → ордер размещён: 53e99c39
```

Всё голосом или текстом. За рулём, на вахте, в ду́ше — не важно.

## Цифры и железо

- **Python 3.11**, systemd-сервис
- **WebSocket** — данные с Bybit в реальном времени
- **30-секундный цикл** — лёгкий (позиции, ордера, health)
- **7-минутный тяжёлый цикл** — scoring, BB, RSI, squeeze, авто-вход
- **Память**: ~200 MB в работе
- **Аптайм**: неделями без рестарта
